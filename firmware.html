Firmware updates

Upload once. Choose a device. Install when you are ready.

Connect

This key permits firmware updates on this hub, even without internet.

1. Choose your device

2. Upload firmware

Upload the sketch .bin from your Arduino build. It must retain SmartSnap OTA support. Uploading does not start installation.

3. Install

Create this ID in the selected home first. The same firmware file can be installed with different IDs. Requires updated SmartSnap firmware; older devices need one normal update with this field blank.

Off keeps the saved home, Wi-Fi and server, and keeps the ID unless one is entered above. On uses the home, Wi-Fi and server settings compiled into the new firmware after a successful update. The ID entered above takes priority. Create the new device in the app first. The old device entry is kept.

The device restarts during installation. Completion is verified when it reconnects with the expected firmware hash.
